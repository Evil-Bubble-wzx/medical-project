# 患者端使用说明

适用版本：本机患者版，交付清单6.0，2026-10-23。

## 打开与登录

1. 双击项目目录 `C:\medical-project\启动患者端.cmd`。服务已运行时直接打开页面；未运行时会启动服务，请保留服务窗口。
2. 患者页面：http://127.0.0.1:8012/patient 。
3. 双击 `C:\medical-project\查看患者试用登录.cmd`，在本机查看账号和密码。账号为 `patient-trial`；不要把密码或API密钥发到聊天中。

已缓存的模型密钥由Windows加密保存，日常启动不需重复输入。该缓存限当前Windows用户和这台电脑使用。首次配置或密钥失效时，按服务窗口提示重新配置。

## 完成一次咨询

1. 填写年龄、主要症状、持续时间；其他信息按需要填写。当前仅用于成人耳鼻喉科合成资料开发试用。
2. 写清想了解的内容，例如：`过敏性鼻炎资料描述了哪些常见症状？`。仅输入“怎么办”时信息可能不足，应补充症状和具体问题。
3. 勾选发送至模型的确认，再点“提交咨询”。症状会随本次提交自动保存，无需另找保存按钮。
4. 等待任务完成。可以刷新页面，重新登录也能恢复已保存的咨询；请勿为催促结果反复提交。
5. 先阅读“患者易懂版”，需要时展开“专业解释与引用依据”，查看原文短引句和来源。输入比较未通过时会明确隐藏，不能把一般知识当作针对本人的诊断。

## 追问与历史

- 在答案下方继续提问，沿用本轮症状；服务器使用本会话最近三轮理解追问，每轮重新检索资料。
- 症状改变时，展开“本次症状”修改；提交后生成新版本，旧咨询保留当时的症状。
- 点击会话中的旧问题，可回到该轮，再基于当时症状追问。
- 新话题点击“开始新咨询”。单个会话最多30轮，达到上限后开始新咨询。
- 在“咨询历史”打开旧会话；有更多记录时点击加载更多。症状版本另在“查看症状资料历史”中查看。
- 提示另一页面更新资料时，点击“核对最新症状，保留当前填写”，核对后再决定提交，不会自动重新调用模型。

## 管理本人资料

展开页面底部“账号与本人咨询管理”：

- **导出可阅读报告（HTML）**：下载可用浏览器打开、打印的报告。
- **导出本人资料与咨询（JSON）**：下载完整结构化记录。
- **删除当前会话**：确认后删除整组问答及相关任务、上下文，症状快照仍保留。
- **清空本人症状、咨询及医生授权**：确认并输入“清空”后，删除当前数据库中的上述本人数据，账号保留，可重新咨询。旧备份仍保留，不是磁盘级彻底擦除。
- **修改密码并退出**：输入当前密码和两次至少12位的新密码；成功后所有旧登录失效，使用新密码登录。本机查看密码工具会同步更新，遇到发布中断会在下次初始化或查看时恢复。

正在排队或运行咨询时，部分删除、清空和改密操作会被阻止；等待任务结束后再操作。

## 遇到没有回答或连接失败

“证据不足”表示本次资料或核验不足，页面不会放出未经通过的草稿。可补充具体问题，或开始新咨询；它不等于已经作出诊断。

连接失败时查看页面提示。选择“准备作为新咨询重试”只会准备表单，仍需你确认并提交；刷新不会自动重复调用模型。会话过期后重新登录即可查看已保存记录。

本版本已验证本机功能和固定开发样例；资料及回答尚未完成医生临床审核，不是医院正式上线版本。页面仅接收合成信息，请勿录入真实身份或病历。
