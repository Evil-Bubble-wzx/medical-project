# PDF与Word导入交付清单4.9

日期：2026-10-22。本轮按已确认范围完成文字版PDF和DOCX导入。入口仍为 http://127.0.0.1:8012/imports 。服务已更新，原咨询和主资料快照保留。

## 本轮实现

- PDF逐页提取正文，DOCX按正文段落、普通表格单元格提取；预览展示原位置和提取警告。DOCX段落号不是Word页码。
- 文件解析在本机独立子进程进行，不调用生成模型、不执行文档宏、不抓取外部链接；支持8MB以内、PDF最多100页、正文最多15万字及最多2000个Word提取位置。解析35秒超时会终止本次解析。
- 先选择文件并检查只读预览，确认后保存原始二进制与SHA-256，准备独立索引；明确启用后才用于新咨询。客户端修改预览文字或伪造位置不能作为文件解析结果入库；服务器核对原文件、解析结果和预览清单哈希。预览24小时有效。
- 分块不跨PDF页、Word段落或单元格，位置保留到检索结果及生成证据包，已有回答引用界面继续显示该定位。源文件和旧引用不改写。
- 加密、损坏、超限文件明确报错。PDF任一页未提取到文字时禁止直接准备，并提示先OCR或核对空白页；嵌套Word表格也禁止直接准备。解析错误、未确认或索引失败不切换主资料库。
- 保留TXT/Markdown与粘贴文字路径；可清除文件改用普通文字，但不冒用原文件位置。来源、许可、成人范围继续由操作人声明，医学状态保持待审。

## 使用与限制

1. 打开导入页，选择PDF或DOCX，等待逐页/逐段预览。
2. 对照原文件检查顺序、缺失、表格和乱码；确认提取文字适合本次开发检索。
3. 填写来源、许可、主题和操作信息，核对范围后准备索引，再明确启用。
4. 返回咨询页提交新问题，展开引用查看原文位置；需要撤回或回滚时进入资料版本管理。

不执行OCR；旧版.doc、扫描图片、嵌套表格不支持直接导入。PDF有OCR文字层时只能提取已有文字层，不能保证其识别正确。复杂多栏PDF的顺序、公式、图注可能失真，必须预览核对。Word图片、页眉页脚、脚注、批注和文本框不提取；表格仅保留单元格文字，合并关系和完整语义需要人工核对。不能把提取成功视为原文完整或医学正确。

本次只实现文件提取预览和引用位置文字，未提供点击引用直接打开本机原文件到指定页的查看器。位置中的字符范围指提取文字，不是PDF二进制偏移。正式医学审核、真实患者政策与院方上线验收仍待完成，不阻塞程序功能开发。本轮未提交或推送GitHub。
