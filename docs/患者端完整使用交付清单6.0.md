# 患者端完整使用交付清单6.0

日期：2026-10-23。范围：本机成人耳鼻喉合成信息患者版。使用方法见[患者端使用说明](患者端使用说明.md)。

## 完成的患者功能

- 独立患者登录；年龄和症状校验；症状与问题一次提交并保存。
- 患者易懂版、专业解释、原文引用；无证据或核验失败时明确收敛，隐藏未通过草稿。
- 多轮追问、历史分支、修改症状保留旧版本、新咨询、历史分页、刷新与重新登录恢复。
- 后台任务状态与人工重试，刷新不重复提交模型请求；并发修改时保留当前草稿，核对最新版本后可继续。
- 本人JSON与可阅读HTML报告导出；整会话删除；清空当前本人症状、咨询和医生授权后可重新咨询。
- 改密撤销全部旧登录；Windows加密登录文件通过持久日志恢复，提交后进程中断不再造成数据库密码与缓存永久不一致。
- `启动患者端.cmd` 作为患者入口，复用已有服务或启动缓存密钥服务；`查看患者试用登录.cmd` 在本机查看密码。

## 本轮修复

1. 密码数据库事务内写入加密恢复日志，提交后发布文件；恢复时核对账号、当前密码哈希及加密内容摘要。未提交、已提交未发布、发布后日志未删三种进程退出点均有独立测试。
2. 资料清空限制在本人当前记录，运行任务期间阻止清空，账号保留。报告通过DOM文本节点转义，不执行症状中的HTML。
3. 历史追问恢复实际所选症状版本，避免错误复用最新症状或重复保存；并发版本冲突提供保留填写的恢复操作。
4. 补充带明确许可与来源的鼻炎比较综述摘要；增加听觉困难表达的检索覆盖。没有修改固定问题以绕过失败。
5. 患者摘要单独语义核验失败时，仅允许一次基于已核验核心事实的修复，并重新执行完整引用与语义核验。仍失败则拒答，跳过相同候选的重复碰运气核验。
