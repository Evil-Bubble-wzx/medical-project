## 使用

先使用scripts/evaluate_answer_generation.py --dataset evaluations/datasets/generation-stratified-dev-1.0.json --output 一个新的报告目录执行明确授权的真实模型评测；该步骤会产生模型调用。

之后使用scripts/report_generation_strata.py --dataset 同一数据集 --run 报告目录 --output 新的JSON文件生成分层报告。追加--compare 第二份报告目录可生成描述性对照。省略--run仅统计样例覆盖和未运行数量，不调用模型。
