# 评测复现与续跑交付清单2.2

## 已交付

- 每次批量生成评测保存manifest.json，并将相同清单写入summary.json。
- 清单绑定开发快照编号、当前有效资料内容指纹、数据集、生成与检索配置、依赖锁、检索模块、评测运行脚本及本地模型清单的文件哈希。
- 续跑必须清单完全一致；旧报告缺少清单时拒绝混用，不改写历史报告。
- 每例运行前后核对本地条件，发现切换或撤回即中止本次评测，不把该例结果混入有效结果。返回的非空检索快照也必须一致。
- 服务器模式开始前检查服务器与本地开发快照编号相同。
- 续跑保留成功、拒答及失败尝试，跳过所有已尝试编号；不会偷偷重跑可能已计费的失败任务。确需重试时，明确选择case-id并新建独立输出目录。
- 发现重复样例编号时拒绝续跑。未完成的报告仍返回非零退出状态，不当作验收通过。
- 正常结束后关闭本地模型API客户端。

## 使用

原命令仍为 scripts/evaluate_answer_generation.py；首次运行指定新的 --output 目录，续跑追加 --resume-from 原报告目录，并使用另一个新的输出目录。可用 --case-id 选择固定合成样例。

成功生成与安全拒答都属于已完成尝试，不等于医学答案正确。人工审核仍为pending。
