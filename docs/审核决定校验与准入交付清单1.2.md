# 审核决定校验与准入交付清单1.2

日期：2026-10-20。

本轮补齐审核表读取、原始资料绑定和分类准入检查。审核表填好后，程序可以判断声明是否完整、对应的题目或资料是否被改动，并输出可追溯报告。程序不直接修改候选集或授予医学合格状态。

## 检查规则

所有条目都必须保留原始身份及内容。审核副本不能直接改题干、引文或资料元数据；候选文件校验和必须一致，缺项、重复或未知条目均阻止就绪。

决定可填 `accept`、`revise`、`exclude`，都需要审核者、带时区日期和具体说明。占位内容、未来日期或误填的数据类型不算有效审核。`revise` 必须先落实到重新绑定的候选版本，不能自动变为接受。

- **来源接受**：成人范围、证据质量、利益冲突说明完整，许可版本与来源家族检查明确为 `true`。
- **证据题接受**：问题清晰、成人适用、证据充分明确为 `true`，范围限制有说明，引用来源已接受；额外相关证据须先绑定，明确没有新增时填写空列表 `[]`。
- **边界题接受**：确认原始预期行为、问题清晰及范围限制；不要求提供医学证据片段，也不要求成人适用性必须为 `true`，因为题目可故意测试人群不适用。
- **归档一致性**：再次核对原文、规范化文件、来源清单哈希以及证据版本、定位、字符范围；拒绝归档目录之外的路径。

## 输出含义

`ready_for_manual_governance_binding=true` 只表示审核声明和绑定结构完整，可进入后续人工治理绑定。它不证明审核者身份、医学判断正确或测试集独立。

以下字段始终不会因本工具通过而自动设为真：

- `clinical_approval`
- `reviewer_identity_authenticated`
- `eligible_for_formal_independent_scoring`

本工具不授予 `human_reviewed`、治理库 `reviewed/published` 或生产资格，不激活资料、不切换索引、不调用模型。来源家族语义核对、审核者认证及正式冻结仍属于后续独立工作。

## 使用方式

继续填写1.1的来源和题目审核副本；不确定内容留待审核，不用为了让程序通过而填默认结论。

```powershell
.venv\Scripts\python.exe scripts\check_candidate_review.py --output evaluations\reviews\新的检查目录\report.json
```

也可用 `--case-review`、`--source-review` 指定另存的审核副本。输出文件必须不存在。退出码0表示声明结构已就绪；退出码2表示仍有待处理项，也包括当前全部待审的正常情况，具体原因见报告。

医学审核沿用上线前统一进行的安排。下一步可补审核界面或审核决定的人工治理绑定；正式独立评分须在审核、语料治理、统一索引和冻结完成后安排。
