# 医学表述集中修复交付清单4.0

日期：2026-10-21。关联总表3.1的F11/F12/F25。旧11项的工程防护和审核材料已交付；独立医学审核及整体质量验收仍未完成。

## 1. 本批修改

| 问题 | 处理 |
|---|---|
| 鼻窦炎语境的12周泛称慢性病 | 使用可信来源题名约束疾病范围；每项保留慢性鼻窦炎语境，题名不补充正文发现 |
| strained译作紧张或紧张感 | 生成与摘要保留原词；针对歧义译法增加拦截，不自行批准中文医学译名 |
| 注意力and行为改成或 | 新增对应引句的关系提示及错误选择关系检查 |
| 解剖相关改成连带影响 | 拦截作用关系扩大；不强制把相关性写成因果 |
| 研究摘要省略研究人群 | 特定中耳炎研究摘要保留研究范围；摘要不得从无研究语境的核心句新增“这项研究” |
| 失代偿性耳鸣泛称严重耳鸣 | 摘要保留亚型；不以严重程度替代原文分类 |

同时修复实际运行发现的相关问题：鼻甲不得无依据细化为下鼻甲；鼻炎共病清单的分类主语不能改成鼻炎自身；核验请求明确每项医学比较支持时至少需要一个本项引用下标。纯输入记录仍先由程序逐字核对，再从远程核验项目中移除，没有自动为医学句补上引用或强行改成支持。

这些是针对已知问题的有限规则和生成指导，不是通用医学逻辑校验器，仍可能漏检或误拒。历史资料、回答和医学审核状态均未自动更改。

实现：`backend/app/retrieval/text_quality.py`、`generation.py`、`patient_summary.py`、`verification.py`。新增测试：`backend/tests/test_paraphrase_limits.py`；补充投影后医学项的引用契约检查，并调整一个同时含译法与关系问题的历史用例对错误优先级的假设。

两个输入探针ANCHOR-TINNITUS-002、ANCHOR-VOICE-003及否认、混合状态案例仍证据不足，未独立证明拒答合理或误拒消失。14例回答中12例只有字面输入记录、1例有医学比较、1例无输入说明；原话记录不算个体医学解释成功。
