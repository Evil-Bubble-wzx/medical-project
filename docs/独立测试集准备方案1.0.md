# 独立测试集准备方案1.0

状态：方案与结构准入校验已完成；现已另存36题候选草稿，但未人工审核、未冻结、未执行评测。详见《证据复核与候选测试集交付清单1.0》。

## 为什么不能拆现有50题

50题已用于开发比较，全部结果已查看；其10份可检索来源均出现在候选结果中。两份没有被原锚点引用的耳鸣资料也已有检索暴露，不能称作未见来源。随机拆分或改写这些问题不能恢复独立性。

独立于调参并不一定要求检索资料在索引之外。测试来源可以进入固定检索语料，但测试问题、证据标签和逐题结果应由审核者保管，在冻结检索参数后才交给评测程序。

## 待收集范围

建议首版30道成人证据题，鼻炎、鼻窦炎、中耳炎、听力损失、耳鸣、咽喉疾病各5道；另6道边界题单独人工评估。数量是收集目标，不是已经存在的测试集。

采用尚未用于当前开发的可靠新来源。先核对许可、成人范围、版本与来源标识，再抽取证据；同一文章不同URL、译文、更新版、共用段落按同一来源家族处理，防止换ID泄漏。必要时减少题数并说明覆盖缺口，不拿同一段落的多个改写凑数。

每题记录 case_id、question、topic、来源家族、原始URL/DOI、document_id、version_id、chunk_id、locator、字符偏移、相关性与充分性理由、适用人群、审核者和审核时间。证据题尽量穷尽相关片段，边界题另记预期处理行为，不以“没有检索结果”代表拒答成功。

知识语料可以共享，但开发与测试标签应按来源家族分组隔离。审核者先完成标签，再看检索排名；测试问题需重新撰写，不复制当前50题或近义改写。

## 准入与执行

`backend/app/retrieval/review.py` 的 `validate_holdout(candidate, development, exposed_documents)` 提供结构校验：拒绝空集、重复ID/问题、当前已暴露来源、缺少证据身份或未记人工审核的题目。标点与空格归一化只能识别简单重复，不能识别语义改写或来源别名。

该函数只检查提交字段，不验证审核人身份，不执行临床审批，也不能防止伪造新文档ID。正式使用前还需按规范来源URL/DOI/内容哈希审核来源家族、逐题核验原文并验证标签绑定的治理快照；通过结构校验不能单独签发正式测试集。

顺序：新增来源及许可核对 → 单独保管并审核题目与标签 → 在开发集决定参数 → 冻结配置/代码/模型/语料快照 → 核验来源与问题隔离 → 一次性运行留出集 → 记录结果。

资料变更后需重新绑定快照和索引，并对所有比较策略采用同一语料。看到测试结果后若据此调参，这个集合降级为开发集，后续泛化评估需另一批未见测试题。

本阶段不代签人工审核，也不把当前空测试集当作交付的有效金标准。
