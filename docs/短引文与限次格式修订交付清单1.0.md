# 短引文与限次格式修订交付清单1.0

日期：2026-10-19。针对两例真实模型输出的quote超过300字符导致结构校验失败。

## 实现

- 生成提示优先8至180字符短引文，明确字符不是英文单词，禁止省略号拼接；要求保留人群、否定和比较等必要限定。
- quote的硬性8至300字符限制不变，不自动截断，不放宽原文匹配。
- 新增可替换QuoteRepairer.repair接口。仅当全部已报告结构错误都是supports中的quote超长时，最多请求一次修订；其他结构错误、未知引用、剂量或语义问题不借此改写。
- 修订响应只能给指定位置的新quote，不能改论断、引用编号或其他字段，必须完整且无重复覆盖错误路径。新引文须同时为原长引文及对应证据正文的连续逐字片段（沿用空白归一匹配）。
- 修订后重新执行完整结构/引用/输入字段/剂量检查，再执行逐论断模型核验；两次资料撤回检查继续保留。任何环节失败隐藏正文，没有修订循环。一次请求最多生成、修订、核验各一次，修订会增加耗时和API用量。
- 页面展示是否尝试及是否通过格式修订，记录初始错误位置和修订元数据，不展示无效原始草稿。配置quote_repair=true，可设false关闭修订。
