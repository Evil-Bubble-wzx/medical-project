# 证据复核与候选测试集交付清单1.0

日期：2026-10-19。状态：工程复核与36题候选集已完成；医学审核、独立测试冻结及激活尚未完成。

## 交付内容

1. `evaluations/reviews/retrieval-audit-1.0/ranking-diagnosis.md` 及 JSON：固定原模型与参数，复算42个原锚点的全语料向量排名、关键词前20排名及融合候选完整排名。原始标签、基线报告和发布状态不变。
2. `evaluations/candidate-library-1.0/`：六份新增开放许可原文、规范化段落、312个候选块及元数据。全部保留人口适用性和医学审核待审状态，不加入原802块检索语料，不改变治理快照或索引。
3. `evaluations/datasets/adult-ent-candidate-1.0.md` 及 JSON：30道证据题、6道边界题，六个主题各6题。证据题绑定候选原文哈希、段落定位、字符偏移、来源链接及DOI；每主题来源家族分组。边界题只提供待审核的处理目标，不给通过分数。
4. `evaluations/datasets/adult-ent-candidate-eligibility-1.0.json`：题目未人工审核，明确未通过独立测试集准入。候选版本是原文哈希标识，不是正式治理版本；snapshot_id为空，不能直接用于现有benchmark。
5. 收集、拟题与排名复核脚本：`scripts/collect_candidate_sources.py`、`scripts/build_candidate_questions.py`、`scripts/refine_retrieval_audit.py`。

## 工程复核结论

原先19道三策略共同未命中题中：13道原锚点不在关键词前20与向量前20的并集中；6道进入该并集，但融合后排名超过10。它们是候选截断与排名的观察，不能由此断言原锚点是唯一相关证据或资料库不存在其他支持。

四个混合丢失单策略命中的案例：

原来的三个补标候选仍保留待审核，不以找回替代段落为理由自动改标签。后续可以在开发集分别试验候选深度和排序，但应先检查问题与证据充分性，且三策略必须使用同一版标签对比。

## 验证及局限

相关测试54项通过，新增/修改文件Ruff检查通过。数据测试逐项核对30道证据题引用的原始XML、规范化哈希及字符切片，确认36题均待审、无检索运行；候选源与旧资料无相同PMCID、DOI或原文哈希，证据题均因待人工审核而未通过准入。

不同PMCID不保证底层样本完全独立；仍需检查同队列、多篇报道、译文和更新版本。题目由同一开发助手编写且已在本次工作中查看，不是盲测金标准；每主题只有一个新增来源，方法题及专题题较多，不能代表全部患者咨询。尚未做完整GRADE评定，也未验证边界行为。

本轮不改变检索配置，不重新宣称评分提升。候选题没有模型性能分数，不直接写入现有评测驱动或医学回答库。
