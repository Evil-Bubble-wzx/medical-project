# 重排序实验交付清单1.0

日期：2026-10-19。状态：本地重排序组件、真实模型对照实验和LangGraph查询验证完成；默认未启用重排。

## 结果与建议

固定原模型与原混合策略候选池，对50道开发题的1,644组问题—段落评分。每题最多40个初始候选，重排后取前10。新增36题未参加；原始标签、配置和资料快照不变。

| 指标 | 原混合检索 | 加入重排序 |
| --- | --- | --- |
| 已知证据Hit@5 | 13/42 | 27/42 |
| 已知证据Hit@10 | 19/42 | 28/42 |
| MRR | 0.2183 | 0.4988 |

新增10道命中，丢失1道（ENT-008）。分主题命中数：听力损失4→7，中耳炎1→5，鼻炎3→5，鼻窦炎7→6，咽喉3→3，耳鸣1→2；每个主题各7题。总体排序改善，但仍有鼻窦炎退步，建议保留为可选开发组件，暂不替换默认配置。

原候选池包含29/42个已知锚点，重排找到其中28个；另外13个原锚点本就不在候选池，重排无法凭空补入。以上仅为待审核开发标签指标，不是临床准确率或独立泛化结果。8道边界题不计命中率，也没有实现或通过临床拒答评测。

## 模型与资源

使用官方 [cross-encoder/mmarco-mMiniLMv2-L12-H384-v1](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1)，Apache-2.0许可，量化ONNX文件约119MB。固定提交 `1427fd652930e4ba29e8149678df786c240d8825`，权重上游SHA256核对通过，tokenizer、配置及README的本地校验和已记录。

本机核查为10个逻辑CPU、约15.6GiB物理内存，核查时可用约3.4GiB；本轮实际使用CPU推理。配置为双线程、批量8、最长512 token，问题与段落成对编码，仅截断文档侧。使用原始单一logit降序，不将其当作相关概率或医学可信度。

模型并非医学专项模型，语言支持不代表中文问题与英文医学段落必然匹配可靠；本轮收益仍需在审核标签和独立问题上验证。

## 耗时与验证

1,644对的批量重排总耗时124.14秒，包含一次模型启动，平均分摊每题约2.48秒。这不是单请求响应时间或P95；原候选检索与查询编码时间另见summary。不能将不含重排的候选检索计时当作重排后总耗时。

71项相关测试通过，新增文件Ruff检查通过。测试覆盖重复候选去重、排序与证据身份保留、非法分数拒绝、非混合入口拒绝、重排期间撤回过滤；模型缺失或失败时明确报错，不回填模拟分数。真实ONNX已完成全部评分，基线指标与原三策略报告一致。LangGraph命令行真实查询成功，返回10条带重排分数的资料；结果保存为 `langgraph-smoke.json`。完整API异步测试本轮未重跑。

## 文件与使用

- `evaluations/reports/reranker-experiment-1.0/report.md`：总体与分主题对照。
- 同目录 `summary.json`、`results.jsonl`：指标、耗时、运行依赖和保护输入哈希。
- 同目录 `ranking-changes.json`：各候选原排名、重排排名、得分及资料定位。
- 同目录 `case-review.md`：10道改善、1道退步的原锚点全文与前3候选原文对照。
- 同目录 `model-manifest.json`、`langgraph-smoke.json`：模型固定版本和实际流程验证记录。
- `backend/app/retrieval/reranking.py`：可替换PairScorer接口与受治理的重排适配器。
- `backend/app/retrieval/rerank_worker.py`：独立离线CPU推理进程。
- `scripts/download_reranker_model.py`、`scripts/experiment_reranker.py`：下载及固定实验入口。
- 《重排序组件使用说明1.0》：接口和CLI使用方式。

手动体验：`scripts/retrieval.ps1 search --mode hybrid --rerank --query "成人鼻炎患者的共病资料有哪些？"`。只有显式添加 `--rerank` 才启用；现有默认及原benchmark保持原行为。
