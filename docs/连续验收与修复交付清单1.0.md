## 交付内容

- 共享模型连接池、仅建连阶段的有限重试；不重发结果不明的已发送请求。
- 模型前处理成人范围、实时医院信息、缺影像、个体处方及缺指南条目的边界。
- 多句草稿按原字符切分，并保留组关系；不丢弃限定后继续展示残句。
- 核验只看每项自身引句及该引句文献标题；标题只用于确认文献范围。
- 修复 e.g. 等缩写和括号被切断导致的引用上下文丢失。
- 百分比与分数必须出现在本项引句中，不从别项借数字或自行换算。
- 可修正的草稿格式或语义问题最多修订一次，修订后重新执行全部检查；核验格式最多重做一次。失败仍拦截。
- 新增独立患者总结节点，只接触一条核心专业事实和其自身引用，再进行完整核验。
- 仅与固定模拟样例完全一致的诊断请求允许返回规范化草稿；普通工作台请求不返回该诊断草稿。
- 服务沿用本机加密密钥缓存和自动重载，本轮无需用户反复输入密钥。
