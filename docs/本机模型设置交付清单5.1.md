## 如何使用

1. 打开设置页，修改所需参数，再保存。保存前不要发起新咨询。
2. 点击检查已保存配置。若模型ID不在列表中，按服务商实际返回的模型ID填写后重新保存；不自动替换模型。
3. 配置冲突时当前填写保留，可先复制意见再重新载入最新配置。
4. 更换密钥需先停止服务，在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start_doctor_trial.ps1 -PromptForKey -NoReload
```

密钥在本机终端隐藏输入，鉴权通过后Windows加密保存。这个步骤只用于换密钥，不用于普通模型参数修改。

## 范围与限制

当前设置页仅支持DeepSeek官方Chat Completions接口，不支持任意第三方网关或Responses协议。超时是单次请求限制，整体咨询仍有独立时限；增加输出上限可能增加用量。连接检查成功不保证实际生成、引用质量或医学正确性。

保存检查不能全面发现旧版本其他进程中未持久化的即时问答；修改前请停止其他共用本项目目录的服务，不要同时手改配置文件。旧配置有文件留存，尚未提供页面一键回滚；需要回退时停机、备份后使用历史generation.json恢复，并重新启动核对。
