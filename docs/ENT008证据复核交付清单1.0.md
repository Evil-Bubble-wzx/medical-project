## 发现

ENT-008询问慢性鼻窦炎按有无鼻息肉分类的资料依据。原锚点位于 `crs-apac-2024 / body/sec[1]/p[1]`，含两种表型的分类文字；其原混合排名9、重排排名14，原文与定位一致，未发现版本、片段ID或引用错配。

重排第2名位于同来源的 `body/sec[3]/p[2]`，原混合排名1。该段含无鼻息肉时归为CRSsNP的文字，并讨论CRSwNP相关诊断内容。这说明前10中存在涉及原问题的其他文本，不能仅凭单锚点未命中就断言没有检索到相关支持。

目前的结论是“标签可能未穷尽，需要判断候选是否充分”，而非“已经通过医学审核”。该长段还包含诊疗描述；后续标注需要避免将整个段落的其他建议自动当成已审核内容。
