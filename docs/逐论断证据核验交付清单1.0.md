# 逐论断证据核验交付清单1.0

日期：2026-10-19。

## 已实现

- LangGraph新增verify_claims节点：检索→草稿→结构/引用校验→第二次模型核验→展示。生成和核验当前同为deepseek-flash，角色提示不同，不宣称独立医学意见。
- 新增可替换ModelVerifier.verify接口及严格核验结构。必须覆盖每项原草稿论断，不允许遗漏、重复、布尔字符串、互相矛盾的支持标签或状态。只保留通过的原句，删除不支持项，不自动改写/补写；删减后缺少专业段、患者段或不能回答问题则返回证据不足。
- 核验失败隐藏正文，核验结束再次检查资料是否撤回。clinical_approval始终为false，semantic_support明确为model_judgment_only或verification_failed，不混淆为人工审核。
- 拒答核验提供justified、possible_over_refusal、uncertain，可能过度拒答必须附本包内逐字摘录，不自动补答。模型无法查看未召回的段落，仍需人工检索复查。
- 结构错误仅记录字段路径、规则类型，未知字段名脱敏；不输出输入值、原始草稿或校验异常正文。页面展示格式定位、模型核验记录和排除数量。
- 原检索默认参数、资料正式审核状态、患者信息持久化策略均未改变；页面输入仍不保存，固定模拟验收结果单独保存至报告目录。

## 实际验证

完整离线回归163项通过，其中生成与核验模块共36项；Python静态检查和JS语法检查通过。测试覆盖原句保留、删减、答案不足、遗漏/重复/矛盾核验、拒答摘录匹配、未知字段脱敏、第二次调用失败及核验期间撤回。未用单元测试模拟输出替代真实模型结果。

真实固定12例均返回流程结果：4例回答、4例证据不足、4例隐藏正文。8份有效核验记录共判定26项论断、排除4项，最终展示22项。025格式失败定位为quote超过300字符；009旧错误未复现，历史未保存草稿，无法回溯其具体规则。043第二次调用建连失败，047缺少过度拒答证据，049核验状态不一致。

全部22项展示论断已作开发一致性复核，发现模型核验仍漏拦无关扩展、部分引文支持不足及结论强度扩大。质量验收未通过；没有医学准确率或临床通过声明。

真实结果与逐条复核：evaluations/reports/claim-verification-1.0/验收与逐条复核1.0.md。原始结果results.json、分项统计verification-summary.json。

旧8例拒答已作开发分类：2例库内有资料但未进入证据包，6例范围/接口/输入边界。记录见evaluations/reports/generation-grounding-fix-final-1.0-complete/八例拒答复查1.0.md。不能把本次包内无证据当作全库无资料。

## 下一步依据

优先修复检索与证据包选择，检查模拟通用主诉等输入是否掩盖实际问题；在可复现的开发集上定位召回与选段损失，再处理论断原子化和直接引文支持。新结果须另建目录，保留本轮失败作为基线。不得为了通过这12题直接硬编码问题与答案，也不应继续单靠同模型判断宣称质量提升。
