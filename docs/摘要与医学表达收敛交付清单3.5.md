## 1. 已实现

| 内容 | 实现与验证 | 限制 |
|---|---|---|
| 摘要输入收敛 | 摘要模型只收到已核验核心句的text，不再收到患者信息、引文、标题或其他专业句；只返回text | 忠实改写一个错误或含糊的核心句仍可能有问题；不是医学真实性证明 |
| 引用由程序保留 | 摘要原样继承核心句全部引用；模型不得另选引用、改写引文或添加来源 | 保存前仍检查原文匹配、统计数值、疾病范围及核心引用归属 |
| 核心事实约束 | 摘要新增焦虑/抑郁/睡眠/注意力等已知概念或新数字时拦截；最终模型也检查摘要不超出核心句 | 有限词面规则及同模型判断会漏判和误拒，不能保证一般语义蕴含 |
| 核心选择 | 按原顺序选首条能通过摘要文本规则的已核验专业句；仅重排专业段，不在选择时新增或删除医学事实 | 没有合格核心句则收敛；随后最终核验仍可能删除不支持的专业项 |
| 核心与摘要共存 | 最终核验若移除摘要对应核心句，整份回答收敛，不允许保留失去核心依据的摘要 | 不用其他专业句替代已删除的核心依据 |
| 拆句索引映射 | 专业核验过滤后及核心重排后，重新映射拆句组的位置，保留组完整性检查 | 审核记录与核心选择记录分别保留各自索引空间 |
| “或”关系 | 对已知音量/音调or来源，中文两项之间必须明确保留或，不能以早先出现的或掩盖后面的顿号/逗号枚举 | 这是针对已发现表达的有限检查，不是通用医学逻辑解析 |
| 否定断言 | 拦截仅凭正面引句断言整份资料未提供因果、风险、比例等医学信息 | 明确的负面证据、单项引句的范围说明、个体病因使用边界不自动拦截；仍需语义核验 |
| 引文上下文 | 已知失代偿耳鸣原文块内，两条无主语短句自动附回同块已注册的完整主语句，作为额外引用 | 只处理两条明确文本模式；不从标题、常识、其他段落或伪造的quote_options补主体 |
| 上下文审计 | 保留所选编号与附回编号，原E/Q编号不重排；引用超过3条时拒绝，不截断或偷偷丢引用 | 直接正文引用不会被自动补充，旧结果不回写；附回上下文不等于自动批准医学论断 |
| 错误定位 | 内容拦截提供段落/序号及有限规则名，供一次修订和归档定位；新增代码可安全保存 | 不保存被拒原始草稿；核验下标故障仍缺足够的逐项定位，尚待补齐 |

## 6. 最终展示内容逐项复核

本执行代理阅读了12例全部54个展示项并逐项对照自有引句和来源题名：39项有限支持、7项需复核、8项精确输入记录；医学文字项实际为46项。**这是同一执行代理的有限文本复核，不是独立专家、临床医学审签或金标准标签。** 这些数目不能作为准确率，也不能与先前不同复核者的计数直接比较。

7项需复核涉及：

1. GEN-ENT-002专业0及摘要0：过敏性疾病谱类目的主语/例子指代可能偏移。
2. GEN-ENT-009专业0及摘要0：CRS语境内的12周被泛称慢性疾病/慢性病，可能被误用于其他疾病。
3. GEN-ENT-002-CONTEXT摘要0：同时伴有加疾病列表可能产生联合发生歧义。
4. ANCHOR-NOISE-001专业2：白噪声风险有引用，但与职业噪声咨询的相关性及暴露语境需审。
5. ANCHOR-NOISE-001摘要0：年龄相关改成年龄增长带来，可能增强因果措辞。

这些是待审核的歧义、范围或相关性意见，不混写成已经证实的医学错误。摘要不新增核心之外的已知概念，并不能保证专业核心本身正确或改写完全不失真。
