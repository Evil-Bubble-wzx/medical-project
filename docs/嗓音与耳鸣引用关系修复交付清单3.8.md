# 嗓音与耳鸣引用关系修复交付清单3.8

日期：2026-10-21。关联总表3.1的F11/F12/F25；本批是针对性修复，不是全系统或临床验收。

## 修改

- 生成请求新增服务端从注册引句构建的relation_constraints：严格绑定E/Q编号，仅匹配两种已知关系。嗓音保留“音量变小或音调变低”；耳鸣保留“影响情绪，并影响睡眠或注意力”。无匹配引句时不生成提示，患者原话不作资料事实。
- 摘要重写明确保留两层连接关系，仍只接收已核验核心句，不增加医学资料或患者信息。
- 耳鸣检查新增情绪与睡眠/注意力之间的错误选择关系检测；仅用于专业句与摘要，不据此改写患者自述。
- 嗓音检查改为按句检查全部匹配关系，避免首个正确表达掩盖后续错误，避免另一句“两者之一”替错误句开脱。保留原有拦截，没有自动修饰或替换模型答案。
- 新增12项回归用例；完整556项离线检查通过，代码检查与格式检查通过。

实现位于`backend/app/retrieval/generation.py`、`text_quality.py`和`patient_summary.py`；新增测试为`backend/tests/test_relation_precision.py`。

## 实际验证

修改前对原固定GEN-ENT-036案例做一次诊断调用，该次本来就回答成功。它说明问题存在随机波动，不能证明3.7被拒草稿是误拦；旧被拒正文未保存，不能倒推具体文本。该次独立保留于`baseline-voice/`，不计入修改后效果。

修改后冻结同版后端，一轮运行6个合成案例：

| 案例 | 本轮 | 观察 |
|---|---|---|
| GEN-ENT-030 | 回答 | 专业句保留情绪“并”睡眠“或”注意力 |
| GEN-ENT-030-CONTEXT | 回答 | 原有and/or错误本轮未出现 |
| GEN-ENT-036 | 回答 | 保留音量与音调的“或” |
| GEN-ENT-036-CONTEXT | 回答 | 专业句及摘要保留“或” |
| ANCHOR-TINNITUS-002 | 回答 | 原话对照不自动推断个体诊断 |
| ANCHOR-VOICE-003 | 核验格式失败 | 内容引用检查通过，最终refusal_supports出现禁止的额外字段，结果保持隐藏 |

合计5答、1格式失败，关系错误拦截0；5例回答严格结构重放通过，当前后端与生成清单指纹一致。上一版同6例为3答、2证据不足、1关系拦截；单次随机运行不能证明稳定成功率。旧3.7中两项具体错误耳鸣文字在新规则下均被拦截。

未重复26例全量模型验证，未新增页面测试。核验格式失败不应强行转成回答或忽略额外字段，尚未在本批解决。嗓音个体输入探针仍未达到可用标准，误拒与医学准确性仍需验证。

本执行代理逐项对照本轮展示内容和引句，未将未发现关系问题的内容标为医学批准。其中GEN-ENT-036-CONTEXT把strained译作“紧张”，专业句与摘要均需术语复核；其他医学内容也仍待独立审核。这些有限规则不能覆盖所有中文同义词、复杂嵌套逻辑或医学语义。
