最终报告：`evaluations/reports/retrieval-three-strategies-1.0/report.md`，逐题对比见同目录 `analysis.md`，逐条结果和运行记录也在该目录。原关键词报告保留为历史记录。

关键词检索已运行50题，其中42题有已知证据：Hit@5为10/42，Hit@10为12/42，MRR约0.1244。这个指标不代表临床准确率，也不是全部相关段落的召回率。

真实向量检索Hit@10为15/42，混合检索为19/42；三策略MRR分别为0.1244、0.1909、0.2183。全部50题均已运行三种策略，共150条逐题结果。混合策略在本开发集总体较好，但中耳炎由关键词2/7降为混合1/7，耳鸣关键词与混合均为1/7、向量为0/7，仍需核查资料与标签。延迟仅包含检索，不含模型加载和批量查询编码，不能当作端到端性能承诺。

验证：资料库、版本治理和新增检索测试共43项通过；新增测试覆盖无模型报错、模型指纹不匹配、损坏向量、撤回隔离、融合去重和指标边界。真实ONNX已在本机CPU运行，802个片段完成384维索引，50题编码及三策略评测成功；LangGraph真实混合检索命令也已通过，结果保存为 `langgraph-smoke.json`。本次没有重跑依赖Windows回环网络权限的完整API异步测试。

## 运行方式

在项目根目录的PowerShell中：

```powershell
.venv\Scripts\python.exe scripts/download_embedding_model.py
.\scripts\retrieval.ps1 build
.\scripts\retrieval.ps1 search --mode hybrid --query "成人耳鸣需要评估哪些信息？"
.\scripts\retrieval.ps1 benchmark
```

每次评测输出新目录。模型下载成功后先构建索引，再跑三策略比较。资料快照变化后需重建索引并重新生成绑定该快照的数据集，不能直接比较不同资料版本的结果。

当前 `configs/retrieval.json` 显式指定本机已有的全局Python用于独立推理子进程；项目虚拟环境保持隔离。该解释器路径仅适用于当前机器。迁移时安装项目的 retrieval 可选依赖并更新 embedding_python；主项目基础依赖锁未变更，推理依赖实际版本随评测记录。

模型来源：[intfloat/multilingual-e5-small官方仓库](https://huggingface.co/intfloat/multilingual-e5-small)，MIT许可；下载器读取许可、固定提交、保存README和文件哈希。默认请求约118MB的量化ONNX文件及约17MB tokenizer，实际以固定提交文件为准。若当前CPU不兼容量化算子，可在下载获准后使用下载器的 `--fp32` 参数并重新建索引、完整评测。
