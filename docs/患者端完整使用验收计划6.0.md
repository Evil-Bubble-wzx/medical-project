# 患者端完整使用验收计划6.0

目标：在已确认的本机合成成人耳鼻喉资料范围内，完整使用患者端；不以医院上线或所有医学问题都能回答为前提。

必须验证：
1. 启动患者入口、登录、错误密码、会话失效与退出清理。
2. 本人症状填写、字段校验、修改保留、自动保存、避免重复提交。
3. 资料问答、通俗回答、专业解释与原文引用；有证据的固定问题可回答，边界或缺证据能明确收敛。
4. 多轮上下文、修改症状、分支会话、新咨询、历史分页与刷新/重新登录恢复。
5. 后台状态、故障提示、明确人工重试；刷新与恢复不重复调用模型。
6. 本人JSON和可阅读报告导出、整会话删除、全部当前症状/咨询/授权清空，禁止越权。
7. 改密、全旧会话撤销、本机加密文件同步；提交后进程骤停能从加密持久日志恢复。
8. 手机布局、导出内容转义、清空后可再次建立症状与咨询。

循环门槛：同一最终代码与配置下两轮完整隔离浏览器通过；一轮完整后端回归；真实模型固定集两轮与实际患者保存链路检查，失败要定位修复后重新验证相关项。所有失败留档，不改变原问题或以安全拒答充当有效回答。

旧备份仍按备份用途保留；当前数据清空不是磁盘取证级擦除。医学审核、真实身份、医院多用户生产部署不属于已确认本机版本，单列边界，不混算完成。
