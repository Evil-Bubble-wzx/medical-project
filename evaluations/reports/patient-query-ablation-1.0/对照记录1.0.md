# 患者查询与证据选择对照记录1.0

日期：2026-10-19。50道原开发题（42道有待审核已知证据锚点、8道边界题），统一模拟年龄35岁、主诉“模拟成人耳鼻喉咨询”。未使用候选36题，不改原标注或资料审核状态。指标为已知锚点命中，不是穷尽相关性或医学准确率。

## 根因和修改

原工作台把问题、年龄及主诉等串成单一检索和重排查询。通用患者描述使若干题的相关段落跌出候选池或前六段。声音嘶哑还存在跨语言关键词缺口：已有“声嘶”英文映射，没有匹配“嘶哑”，向量召回也未补足。

新策略先按问题检索，再按问题及完整患者背景补充检索；固定RRF常数60、问题路权重2/背景路1，去重后最多50候选，以问题重排，前10结果仍按原规则选最多6段。未引入疾病题号映射、手工指定答案或自动放宽人群规则。背景仍参与第二路召回，生成与核验继续收到完整原始模拟输入。

通用别名新增“嘶哑→hoarseness”；不更新向量模型或重建索引。该新增别名只影响这套题中的036、040，重算这两题，其余48题复用查询内容未改变的双路结果。非独立测试，不据此宣称泛化效果。

## 验证与复现边界

原查询三方案共实际评分5399对，CPU批量评分约401秒；这不是在线P95。最终方案多一次检索/查询向量计算，候选上限从40增至50，在线开销需另测。保留问题单路对照用于区分查询构造与额外候选数量的作用，但尚无真实患者样本或多种背景干扰的独立验证。

执行scripts/experiment_patient_queries.py复现旧别名表下的三方案，该脚本进程内移除新增嘶哑别名以冻结前修复行为；scripts/experiment_hoarseness_alias.py重算受别名影响的两题；scripts/summarize_patient_query_experiment.py合并结果。原实验输入哈希、快照和模型指纹在summary.json，按题排名在details.json，补词后完整50题详情在after-alias-details.json。配置只在实验成功后切换，历史报告未覆盖。

当前配置patient_query_policy=dual_question_first；可改回combined回滚工作台查询构造，通用别名单独保留。新策略仅接入工作台，不改底层通用RetrievalEngine默认参数，也不擅自启用生产资料快照。
