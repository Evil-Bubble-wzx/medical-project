# 检索审核入口1.0

本包基于已冻结的50题、150条检索结果与开发资料快照生成，不修改基线标签或计分。

后续工程复核已增加 `ranking-diagnosis.md` 和同名JSON，给出全库向量及完整融合候选排名。新增36题草稿位于 `evaluations/datasets/adult-ent-candidate-1.0.md`，它尚未成为通过审核的独立测试集。

## 结果

- 42道证据题中，19题三策略均未命中原锚点。
- 混合策略未命中23题，其中4题被单独的关键词或向量策略命中。这些标记有重叠，不能相加。
- 8道边界题保持人工审核，不把检索有结果当作允许回答。
- 全部42个原锚点的版本、定位及字符偏移均可对应当前受治理片段。这只证明定位一致，不证明医学相关性。
- 2道题提出共3个补充证据候选，全部待审核；没有重新计算“提升后的分数”。

资料分布也值得检查：802块中531块属于耳鸣主题来源，约66.2%。这是可观测的数据不均衡，不足以证明它导致某一题失败；后续实验可验证来源多样性或篇幅均衡的影响。

## 文件与操作

- `evidence-review.md`：50题逐题原锚点全文、三策略排名、各策略前三候选全文与来源定位。完整前10仍在原始报告的 `results.jsonl` 中。
- `review-queue.json`：待处理队列。优先四个退步案例，再查19个共同未命中案例，最后审核8个边界案例及其余控制案例。
- `proposed-label-additions.json`：候选补标，保留 `decision=null`、`reviewer=null`。审核者需判断相关性、充分性、成人适用性、证据时效和许可，记录接受/拒绝及理由。不得仅因系统检索到了就接受。
- `summary.json`：统计、资料来源暴露清单、数据与代码哈希。
- `holdout-eligibility.json`：当前严格来源隔离测试集为空，准入失败；这是明确的未就绪状态。

审核后创建新的数据集版本，记录原标签与新标签的差异。在相同新标签上重新比较全部策略；保留旧报告，禁止只给某一策略增加有利标签。

目前自动完成的是工程一致性检查与错误分流。临床复核尚未完成，资料缺口也没有被自动确诊。独立测试集的准备要求见 `docs/独立测试集准备方案1.0.md`。
